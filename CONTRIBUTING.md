# Contribuer

Ouvre une issue décrivant un problème reproductible ou une amélioration.
Une pull request doit expliquer le changement et ses vérifications.

Contributions utiles : tests de reprise après interruption; exactitude des
frais; jeux de données publics documentés; évaluation hors échantillon;
accessibilité d'un futur tableau de bord; traduction de la documentation.

Ne soumets ni clé API ni données personnelles. Ne présente pas un résultat
synthétique comme un gain réel. Toute intégration d'argent réel doit faire
l'objet d'une conception distincte et explicitement revue.
